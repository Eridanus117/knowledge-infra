# ADR-035：知识来源身份取自登记表逻辑名称

## 背景

检索投影需要稳定的来源段来构造文档身份、过滤中央集合、执行来源范围剪枝，并让评估工件引用同一对象。如果这一段从物理目录名、挂载点、机器位置或部署坐标派生，正常迁移就会制造新的身份。结果是同一材料出现重复投影、旧条目无法清理、评估案例失配，或读取方无法知道自己引用的是哪个来源。

逻辑名称与物理承载本来就是不同概念：登记表负责声明“这是谁”，物理位置负责说明“当前从哪里读取”。本决定将两者明确解耦。

## 决定

### 1. 来源身份只取自登记表逻辑名称

每个知识来源必须在登记表中拥有唯一、规范化的 `source_id`。文档的稳定身份由以下逻辑部分组成：

```text
source_id + domain + document_slug
```

编译、同步、查询、剪枝和评估必须使用登记表中的 `source_id`。它们不得从物理目录名、当前位置、机器配置或临时别名重新推导来源身份。

登记表是来源身份的唯一权威；它不是源材料正文的第二事实源。源材料仍然负责文档内容和规范元数据，登记表只负责把逻辑来源绑定到其当前可读取承载。

### 2. 物理迁移不改变逻辑身份

来源改变物理承载、重组层级或更换读取位置时，保持原 `source_id`。中央投影可使用同一逻辑身份重建，已有引用、评估案例和来源范围规则继续成立。

若确实需要变更逻辑名称，这是一项显式身份迁移，而不是随目录改名自动发生的副作用。迁移必须声明旧身份、新身份、映射范围、冲突处理、投影重建顺序和旧身份条目的来源范围清理计划。

### 3. 身份不一致必须阻断，而非猜测

以下情况必须失败并输出不泄露物理位置的诊断：

- 登记表缺少来源逻辑名称；
- 两个来源规范化后使用相同名称；
- 编译输入的来源身份与登记表不一致；
- 投影条目的 `source_id` 与本次同步范围不一致；
- 评估案例、基线或候选引用无法解析的来源或文档身份；
- 身份迁移映射不完整或存在一对多歧义。

系统不得为“方便继续”改用物理名称、最近匹配或环境默认值。身份不明确时失败，比用错误来源继续发布更安全。

### 4. 中央集合剪枝必须使用该逻辑身份

在中央集合中，`source_id` 是单来源同步、孤儿检测和删除范围的唯一键。同步 `source-alpha` 时，只可触及标记为 `source-alpha` 的条目。若计划涉及 `source-beta`、`source-gamma` 或 `source-delta` 的条目，必须中止并报告跨来源操作，而不是把它们当成孤儿。

### 5. 公开评估以逻辑身份为比较单位

匿名评估案例和基线必须引用登记表逻辑身份，而不是任何物理位置。公开评估器不得使用未声明的默认案例、基线或参考分数；输入缺失、来源身份不匹配、文档身份无法解析或候选与基线覆盖集合不同，均必须失败并输出诊断。只有身份可比的评估结果才可用于切换默认行为。

## 合成示例

以下示例完全合成。

- 登记表将一个来源命名为 `source-alpha`。它的物理承载发生迁移后，文档身份仍以 `source-alpha` 开头，中央投影可以安全重建。
- 另一个来源当前承载名称恰好与 `source-alpha` 相似，但登记表逻辑名称为 `source-beta`。两者不因物理名称相近而合并。
- 一次同步请求声明 `source-gamma`，却计划删除带有 `source-delta` 身份的条目。系统输出 `cross_source_prune_blocked` 并拒绝应用计划。
- 一个匿名基线引用 `source-alpha`，候选投影只声明 `source-beta`。公开评估器输出 `identity_mismatch` 并失败，不尝试寻找替代身份或默认分数。

## 后果

### 正面

- 物理迁移、重命名和部署变化不再造成检索 identity 漂移。
- 中央集合的过滤、剪枝和诊断都使用同一个稳定键。
- 身份冲突会在发布前暴露，而不是在召回异常后才被发现。
- 公开评估可在匿名逻辑身份上复现，而无需暴露承载位置或原始材料。

### 代价与约束

- 登记表名称是长期兼容性接口，创建、改名和退役必须受治理。
- 身份迁移需要显式计划和可审查映射，不能只改物理位置。
- 调用方必须传递逻辑来源身份；依赖环境推断的旧接口需要被移除或改为失败。

## 否决的替代方案

| 替代方案 | 否决理由 |
|---|---|
| 以物理目录末段作为来源身份 | 重命名或迁移会改变身份，导致重复和无法清理。 |
| 用完整物理坐标作为来源身份 | 将持续变化的布局焊入长期引用，迁移成本更高。 |
| 让登记表名称迁就当前物理名称 | 倒置逻辑与承载的关系，无法提供稳定引用。 |
| 身份不确定时选择最接近的名称或环境默认值 | 会把错误来源伪装成成功，损害投影和评估可信度。 |

## 不在范围内

本决定不规定登记表的具体序列化格式或物理承载技术。它只规定逻辑来源身份的权威来源、迁移语义、中央集合剪枝边界和失败语义。
