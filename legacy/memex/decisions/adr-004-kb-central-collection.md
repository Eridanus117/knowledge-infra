# ADR-004：中央检索集合与来源范围剪枝

## 背景

多个知识来源需要联合检索，但每个来源各自维护独立投影会把一次检索拆成多次查询、合并和去重。这样不仅增加读取路径，还会让新鲜度、权限和清理规则分散在多个地方。

中央化并不意味着混淆来源。源材料继续由各来源独立拥有；中央集合只是统一的、可重建的检索投影。中央化最危险的操作是清理孤儿条目：如果一次同步把其他来源的条目也当成孤儿，中央化会从便利变成数据丢失风险。

## 决定

### 1. 使用一个中央、可重建的检索集合

所有允许联合检索的来源发布到一个中央投影。每个条目必须保留以下不依赖物理位置的 payload：

- `source_id`：来自逻辑登记表的来源身份；
- `document_id`：来源内稳定文档身份；
- `domain_segments`：规范化后的领域段；
- `kind`：源声明的文档种类；
- 来源版本、投影策略版本和内容摘要标识。

联合检索是一次检索加显式过滤，而不是对若干来源分别 fan-out 后再拼接结果。逻辑来源、领域和种类可用于收窄结果；它们不是对物理目录或机器位置的替代表示。

### 2. 中央集合切换与来源范围剪枝必须原子生效

同步单一来源时，孤儿检测和删除操作必须同时带上该来源的 `source_id` 约束。没有来源范围的剪枝不得在中央集合上执行。

实现必须满足以下失败语义：

- 请求中央集合同步却没有指定来源身份时，立即失败并输出 `source_scope_required`；
- 请求的来源身份不在登记表中，立即失败并输出 `source_identity_unknown`；
- 计划删除的条目中出现其他来源身份，立即失败并输出 `cross_source_prune_blocked`；
- 只有明确、单独发起的全量对账流程才可检查所有来源，且它必须生成可审查计划后才允许应用。

中央集合的指向变更、写入方启用和来源范围剪枝能力属于同一个 cutover。任何只完成其中一部分的部署都不是有效切换。

### 3. 规范化过滤维度

领域过滤使用规范化后的段，而不是字符串前缀猜测。写入路径和读取路径必须使用同一规范化规则，因此相同的领域请求不会在不同投影中产生不同含义。种类字段可以参与排序或显式调用方过滤，但默认不会作为未声明的跨来源排除条件。

### 4. 用显式评估门保护切换

每次改变中央投影、过滤维度、剪枝语义或默认检索行为，都必须通过匿名评估集与固定基线的比较。公开评估器必须从调用方显式接收这些输入；不能寻找未公开默认位置或未提供的历史分数。若输入缺失、来源集合不一致、案例身份不一致或基线版本不匹配，评估必须失败并给出诊断。

## 合成示例

以下示例完全合成。

1. `source-alpha` 与 `source-beta` 都发布到中央集合。一次联合检索可用 `source_id` 或规范领域段收窄，而不需要分别发起两次检索后合并。
2. `source-alpha` 同步时，预期条目集合只与 payload 中 `source_id=source-alpha` 的条目比较。`source-beta` 的条目不在此次孤儿判断范围内。
3. 一个同步调用省略来源范围。系统拒绝执行，输出 `source_scope_required`；它不会尝试“推测”范围。
4. 一个匿名评估案例集声明自己覆盖 `source-alpha` 与 `source-beta`，而提供的基线只声明 `source-alpha`。评估器输出 `identity_mismatch` 并失败，不产生可用于晋升的结果。

## 后果

### 正面

- 联合检索、过滤和可观测性有一个一致入口。
- 逻辑来源身份随物理迁移保持稳定。
- 单来源同步的删除爆炸半径被限制在该来源内。
- 中央化后的评估可检查联合结果与单来源收窄结果，而无需依赖原始材料。

### 代价与约束

- 中央集合的写入格式需要长期维持来源身份和策略版本。
- 对账与清理不再是可随意运行的维护命令；它们必须先证明范围。
- 读取方必须把筛选条件记录为请求的一部分，不能把隐式环境状态当作过滤来源。

## 否决的替代方案

| 替代方案 | 否决理由 |
|---|---|
| 每个来源永久单独检索，再在调用方合并 | 扩大调用方复杂度，并让排序、去重和过滤语义分叉。 |
| 中央集合上允许无范围孤儿剪枝 | 会把本次同步未见到的其他来源误判为孤儿。 |
| 用物理位置作为来源过滤键 | 物理迁移会改变结果身份，不能作为稳定边界。 |
| 靠隐式默认评估数据判断切换质量 | 输入不可审计，且不能保证候选与基线可比。 |

## 不在范围内

本决定不要求所有来源进入同一访问域。访问控制或隔离策略可以限制哪些来源允许发布或读取；一旦某来源允许进入中央投影，它仍必须遵守来源身份和来源范围剪枝契约。
